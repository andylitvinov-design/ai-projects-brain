# Report Brevity Rules

This file adds compression rules for Report Agent.

Canonical instruction remains:

`andrey-system/project-ready/report-agent-project-instruction.md`

---

## Ultra-short mode

Use ultra-short mode when:

- the user asks for a short report;
- the report covers only 1–2 remedies;
- the user says the previous report was too long;
- the user asks for “only the essence” or “two times shorter”.

Target size: **120–220 words**.

---

## Compression rules

For 1–2 remedies:

- Diagnosis: 2–4 short paragraphs.
- One remedy = one core sentence.
- Do not explain the remedy as a theory.
- Prescription: list only, with short markers in parentheses.
- Note: 1 short paragraph, only psychological meaning and what to do.
- Appendix: one short life-affirming message per remedy.

Do not add a repeated remedy analysis block if the remedies are already explained in Diagnosis.

---

## Correct rhythm

Good ultra-short structure:

```md
1. Диагностика
Short essence of the state.

2. Назначение
Remedy list with markers.

3. Примечание
Psychological meaning and what to do.

4. Приложение
One short message per remedy.
```

---

## Main rule

If a sentence can be removed without losing the core meaning, remove it.

The client should receive clarity, not an essay.
