# Report Depth Without Length Rule

Status: canonical global supplement for Report Agent and Report Style Auditor.

This rule applies to **all** client reports, notes, remedy decoders, Bach reports, Wu Xing diagnostics, progress checks, and psychosomatic summaries.

Main principle:

**Expanded input means deeper and more accurate analysis inside the agent, not a longer client-facing report.**

A report is stronger when it is:

- more precise;
- better prioritized;
- more accurate in the weak link;
- clearer in psychodynamics;
- more directly connected to remedies/support;
- easier for the client to read.

A report is not stronger because it is longer.

---

## 1. Core rule

When the user gives more incoming data, the agent must use it to improve:

1. the main conclusion;
2. the remedy logic;
3. the weak link / growth point;
4. the psychodynamic / psychosomatic context;
5. the next check.

Do **not** use more incoming data to create more paragraphs by default.

The client should receive the distilled result, not the full reasoning process.

Formula:

```md
more data → sharper conclusion, not longer report
```

---

## 2. Expanded vs long

Expanded report does **not** mean:

- longer introduction;
- long retelling of input;
- separate paragraphs for every measurement;
- repeating the same idea in different language;
- full theory of Wu Xing / Dao / remedies;
- a second diagnosis inside psychodynamics.

Expanded report means:

- the conclusion is more exact;
- the weak link is named more precisely;
- psychodynamics is deeper but shorter;
- remedies are explained as functions inside the current mechanism;
- priorities are clear: main layer vs secondary layer;
- the next check is specific.

---

## 3. Universal short structure

For most client-facing reports, start from this compressed structure and expand only when necessary:

```md
## 1. Вывод

One compact paragraph with the main state / dynamic / meaning.

## 2. Что показывают препараты / стихии / данные

Short explanation of the incoming signals.
Only what changes the conclusion.

## 3. Слабое звено / точка роста

One clear paragraph.
Name the main weak link and the next growth movement.

## 4. Психодинамика / психосоматика

Very compact.
Explain the deeper context of inner work.
Do not turn this into a second full report.

## 5. Назначение / следующий шаг

What to take / do / observe.
When to recheck.
```

The headings may be adapted, but the logic should remain:

**вывод → сигналы → слабое звено → психодинамика → действие / проверка**

---

## 4. Psychodynamic / psychosomatic rule

Psychodynamics is not a place to write a long interpretation.

It must answer briefly:

- what inner pattern this points to;
- what the person is learning now;
- what needs to soften / strengthen;
- what kind of work on self is relevant.

Good:

```md
В целом это про переход от “держаться и контролировать” к “можно немного выдохнуть”. Работа сейчас — меньше заставлять себя, меньше спешить, больше чувствовать безопасную опору в теле.
```

Bad:

```md
This state indicates a complex interaction of Water, Wood, Fire, Earth, and Metal in which early defensive strategies, emotional regulation, and somatic adaptation form a multilayered pattern...
```

---

## 5. Remedy / support explanation rule

Do not describe remedies as encyclopedia entries.

Explain remedies as signals and support functions in this exact case.

Good:

```md
Mimulus по Воде говорит о страхе расслабиться и довериться потоку.
Wild Oat по Огню — о новом импульсе, который ещё не оформился, но уже зреет.
```

Bad:

```md
Mimulus is traditionally used for known fears and may help clients who experience anxiety in daily life.
```

---

## 6. Density check before sending

Before sending any client-facing report, ask:

```md
Can this be 30–50% shorter without losing meaning?
```

If yes, shorten it.

Then ask:

```md
Did the added input make the report sharper, or only longer?
```

If it only became longer, rewrite.

---

## 7. Auditor rule

When auditing reports, penalize not only repeated text, but also false expansion.

False expansion means:

- the report is called extended but only contains more words;
- extra input is copied into the report instead of distilled;
- psychodynamics is long but not more exact;
- remedy descriptions are longer but not more connected to the mechanism;
- the weak link is still vague.

Correct audit verdict:

```md
Needs rewrite: expanded input was not distilled into sharper conclusion; the report became longer instead of deeper.
```
