# Quality Checklist — Andrey Li System

Use this checklist for any output: report, content, offer.

## Core Questions

- Is the client problem clear?
- Is the mechanism explained?
- Is resource identified?
- Is there a next level?
- Are there practical actions?
- Is there a clear result?

## For Reports

- includes current level
- includes mechanism
- includes Wu Xing
- includes actions
- includes next step

## For Content

- has a clear hook
- uses simple language
- connects to pain
- shows mechanism
- leads to action

## For Offers

- clear problem
- clear result
- clear process
- clear next step

## Anti-Patterns

- too abstract
- too long without value
- no clear result
- no connection to client reality
