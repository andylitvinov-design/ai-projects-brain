# Bach Remedy Short Markers

This file is a compact marker reference for Report Agent prescriptions.

It is not an alternative report template. The canonical writing rules remain in:

`andrey-system/project-ready/report-agent-project-instruction.md`

Use this file only to choose short client-facing markers in parentheses after Bach remedies.

Format:

```md
Remedy (ключевая суть)
```

The marker must name the key inner state or support direction, not the plant/tree/fruit name.

Good:

```md
Sweet Chestnut (опора в пределе)
Cherry Plum (удержание формы)
Mustard (дефицит света)
```

Bad:

```md
Sweet Chestnut (сладкий каштан)
Cherry Plum (алыча)
Mustard (горчица)
```

## Usage rule

In `## 2. Назначение`, use the marker in parentheses:

```md
1) Mustard (дефицит света)
2) Sweet Chestnut (опора в пределе)
3) Scleranthus (колебание)
```

Do not use botanical translation in parentheses unless the user explicitly asks for translations.
