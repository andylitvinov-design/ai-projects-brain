# Short Direct Style Addendum

Status: required QA addendum.

Do not rewrite Andrey into a polished essay.
Keep the report short, direct, alive, and diagnostic.

Final text should keep:

- number first;
- main state;
- image;
- conflict;
- support;
- next check.

Avoid:

- polished article tone;
- long smooth paragraphs;
- abstract psychology instead of concrete mechanism;
- polite labels that remove the sharp point.

Required check:

1. Did the rewrite become too literary?
2. Did it keep Andrey's short and direct rhythm?
3. Did it preserve the mechanism?
4. Does it read like a living note rather than a book?

If the text is clean but sounds like a book, live style cannot be above 6/10.
