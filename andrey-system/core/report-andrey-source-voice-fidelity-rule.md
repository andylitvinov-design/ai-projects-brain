# Report Andrey Source Voice Fidelity Rule

Status: canonical supplement for Report Agent.

Use this rule when Andrey gives his own draft, rough note, checked remedies, or live diagnostic text.

Main rule:

```md
Andrey source text → preserve voice first → clarify only what helps → do not beautify beyond his tone.
```

The task is not to rewrite Andrey's draft into generic therapeutic prose.

The task is to keep his living diagnostic rhythm and make the text clearer, safer, and more client-ready.

Preserve:

- short diagnostic phrases;
- direct field-check language: “посмотрел”, “вижу”, “чуть”, “как защита”, “ресурс упал”, “здесь можно помочь”;
- cautious wording;
- simple movement: cause → state → support → check;
- natural roughness when it makes the text feel alive.

Correct only:

- grammar and readability;
- unclear remedy hierarchy;
- over-promising wording;
- excessive certainty;
- repetitions that make the report longer but not more precise.

Do not over-polish.

Bad:

```md
Сейчас задача дать системе мягкую поддержку: тепло, вода, отдых, спокойный контакт и минимум давления. Чем меньше внутреннего нажима, тем быстрее может вернуться естественная опора.
```

Better:

```md
Сейчас лучше не давить. Ресурс просел, поэтому границы чуть закрылись. Лучше дать мягкую поддержку: тепло, вода, отдых, спокойный контакт. Потом перепроверить динамику.
```

Before sending a report based on Andrey's draft, ask internally:

```md
Does this still sound like Andrey, or did it become polished generic therapist prose?
```

If it became generic, rewrite closer to Andrey's raw diagnostic voice.
