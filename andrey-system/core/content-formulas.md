# Content Formulas — Andrey Li System

This file defines how to generate content that converts.

## Core Rule

Content must always follow:
Problem → Hidden cause → Mechanism → Result → Call to action

Avoid theory-first content.

## Main Angles

### 1. Stuck State

Hook:
"If you feel stuck, it is not random."

Structure:
- describe the state;
- name the hidden mechanism;
- show that it can be changed;
- invite to diagnosis.

### 2. Energy Problem

Hook:
"Low energy is not laziness."

Structure:
- challenge belief;
- explain compression;
- connect to resource;
- show direction.

### 3. Money / Business Block

Hook:
"If your income does not grow, there is a system bottleneck."

Structure:
- show external symptom;
- connect to internal mechanism;
- show leverage point;
- offer analysis.

### 4. Clarity Problem

Hook:
"Confusion is a system state, not your personality."

Structure:
- normalize confusion;
- explain lack of structure/resource;
- show that clarity can be built;
- invite to work.

## Short Post Formula

1. Problem (1–2 lines)
2. Hidden cause
3. Mechanism insight
4. Result
5. CTA

## Example Skeleton

You are stuck.

Not because you are weak.
But because your system is compressed.

When compression is removed, energy and clarity return.

I help identify and remove this mechanism.

## Core Hooks

- You are stuck not because you are weak
- There is a mechanism behind your problem
- Fix the system → result changes
- Energy is a function of system state
- Clarity appears when compression is reduced

## CTA Options

- request express diagnosis
- send message
- ask for analysis

## Content Rules

Always:
- speak client language;
- be concrete;
- connect to result;
- show mechanism simply.

Avoid:
- long theory;
- abstract philosophy;
- vague motivation;
- empty inspiration.
