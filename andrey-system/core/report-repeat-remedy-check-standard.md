# Repeat Remedy Check Standard — Andrey Li Reports

Status: canonical
Owner: Andrey Li
Scope: repeat report / remedy relevance check / Bach repeat check / progress check with previous remedies

This file defines the canonical structure and style for repeat reports where Andrey checks what changed after a previous remedy / Bach / support set and selects the current support.

Main rule:

**A repeat report must not only say what is current. It must explain what changed and what shows that previous remedies have left or become background.**

---

## 1. When to use

Use this format when:

- there was a previous report or previous support set;
- the user asks to recheck a person / state / remedy set;
- old remedies may have worked through a layer;
- the task is to see what left, what remains, and what is now central;
- Bach essences are used as diagnostic signals;
- Wu Xing / Dao may be present, but the report is primarily a repeat relevance check.

Correct format name:

```md
Повторный отчёт / проверка актуальности препаратов
```

or shorter:

```md
Повторная проверка
```

If Wu Xing is included, the format becomes:

```md
Deep + Repeat Remedy Check
```

but it still follows the repeat-check structure below.

## 3. Required blocks

A repeat report must include these blocks:

1. **Диагностика** — current state and current core.
2. **Что изменилось** — what left / became background.
3. **Что говорит, что они ушли** — the old remedies no longer describe the central mechanism.
4. **Что показывают препараты сейчас** — current remedies by function.
5. **Вывод** — psychodynamic formula and bottleneck.
6. **Решение** — what inner support must be restored.
7. **Назначение** — main and optional support.
8. **Проверка** — timing and what to observe.

Hard requirement:

```md
Never write only:
"Почти ушли / стали фоном: X, Y, Z."

Always explain:
"Они ушли / стали фоном because they no longer show the center of the current state. They showed the old layer: ..."
```

## 4. Canonical Sofia example

This is the primary style model for the format.

```md
1. Диагностика

Смотрю.
София сейчас как будто в состоянии внутренней борьбы.
Ресурса немного не хватает, поэтому она держится за связь и ищет через неё дополнительную опору.

Главное ядро сейчас — Chicory.
Это тема связи: хочется быть рядом, получать ответ, чувствовать заботу — и есть риск удерживать контакт напряжением.

2. Что изменилось

Ушли или стали фоном препараты, которые показывали старый слой:

- Olive — полное истощение.
- Vine — жёсткое давление и попытка управлять ситуацией.
- Clematis — уход из контакта, выпадение из присутствия.
- Water Violet — холодная дистанция и закрытость.
- Agrimony — маскировка боли через “всё нормально”.

Это говорит, что стало меньше защитного слоя.
Больше настоящести.

Но вместе с этим София ближе подошла к внутреннему стрессу и боли, которую раньше можно было прикрывать, контролировать или обходить.

3. Что показывают препараты сейчас

- Chicory — связь очень важна, но её важно не удерживать напряжением.
- Sweet Chestnut — внутренний предел: старый способ держаться уже не работает, нужна новая опора.
- Star of Bethlehem — след сильного переживания, сердце ещё восстанавливается.
- Elm — перегруз ответственности: “я должна справиться”.
- Vervain — перевозбуждённая попытка всё удержать и быстро исправить.

4. Вывод

Психодинамика ситуации сейчас такая:

“Я должна выдержать, удержать связь и не развалиться”.

Есть попытка собраться, справиться, сохранить контакт и не потерять внутреннюю опору.

Главный bottleneck — не отсутствие силы, а перегруз удержания.
София пытается одновременно быть сильной, переживать боль и сохранять связь.

5. Решение

Главная задача сейчас — восстановить чувство личной опоры.

Чтобы не нужно было всё контролировать, стараться всё удержать и цепляться за связь.
Нужно вернуть опору на себя: “я могу быть в связи, но не терять себя”.

6. Назначение

В первую очередь подходят эссенции Баха:

- Chicory — поддержка здоровой связи без удерживания.
- Sweet Chestnut — поддержка в состоянии внутреннего предела.
- Star of Bethlehem — мягкое восстановление после сильного переживания.

Дополнительно, по желанию:

- Elm — если остаётся перегруз ответственности.
- Vervain — если есть перевозбуждённый контроль и желание срочно всё исправить.

Принимать: налить немного воды, добавить по 4 капли каждого препарата.
Принимать 2–4 раза в день.

Курс: 2 недели.
Повторная проверка — через 1–2 недели.

7. Ожидаемое направление поддержки

Может стать больше внутренней силы, спокойствия и способности опираться на себя.

Главный эффект, который проверяем:
меньше цепляния за связь, меньше внутреннего напряжения, больше чувства “я справлюсь и останусь в контакте с собой”.

8. Приложение. Послания препаратов

Chicory: я могу любить и быть в связи, не удерживая другого напряжением.

Sweet Chestnut: даже в пределе во мне может родиться новая опора.

Star of Bethlehem: моё сердце может постепенно оттаивать после сильного переживания.

Elm: я могу справляться не через перегруз, а через распределение силы.

Vervain: мой огонь может быть живым, но не сжигать меня изнутри.
```

## 5. Style rules

Use living Andrey style:

- `Смотрю.`
- short paragraphs;
- direct current-state language;
- remedy as a function in this mechanism;
- one clear psychodynamic formula;
- one bottleneck;
- one solution direction;
- safe wording for expected effects.

Good phrases:

```md
Состояние сменило слой.
Старый слой ушёл / стал фоном.
Это говорит, что стало меньше защитного слоя.
Больше настоящести.
Но вместе с этим ближе проявился внутренний стресс.
Главный bottleneck — ...
Главная задача сейчас — ...
Проверяем: ...
```

Avoid:

```md
Почти ушли: X, Y, Z.
```

unless it is immediately followed by:

```md
Они ушли, потому что уже не описывают главный центр состояния.
Раньше они показывали ...
Сейчас центр сместился к ...
```

## 6. Remedy relevance logic

When saying a previous remedy has left, explain it by its old function.

Example:

```md
Ушли препараты, которые показывали:
- Olive — полное истощение.
- Vine — жёсткое давление и попытки управлять.
- Clematis — уход из контакта.
- Water Violet — холодную дистанцию.
- Agrimony — маскировку боли.
```

Then add the meaning:

```md
Это говорит, что старый защитный слой стал слабее.
Сейчас больше настоящести, но ближе контакт с внутренним стрессом.
```

This is required. Without it, the report is incomplete.

---

## 7. Safety rule

Do not promise guaranteed effects.

Bad:

```md
При приёме данных препаратов растёт внутренний огонь и способность справиться.
```

Good:

```md
Ожидаемое направление поддержки: может стать больше внутренней силы, спокойствия и способности опираться на себя.
```

Use:

- может поддержать;
- ожидаемое направление поддержки;
- проверяем;
- при тяжёлом состоянии не заменяет медицинскую / психологическую помощь.

## 8. Audit checklist for this format

Before accepting a repeat report, check:

```md
Тип отчёта: Repeat Remedy Check / Progress Check
Есть текущая диагностика: да/нет
Есть блок “Что изменилось”: да/нет
Старые препараты объяснены через старый слой: да/нет
Понятно, что говорит, что они ушли: да/нет
Текущие препараты объяснены через текущий механизм: да/нет
Есть psychodynamic formula: да/нет
Есть bottleneck: да/нет
Есть решение / direction of support: да/нет
Есть назначение: да/нет
Есть повторная проверка: да/нет
Эффект сформулирован безопасно: да/нет
```

If the answer to “Понятно, что говорит, что они ушли” is **no**, the report must be revised before sending.
