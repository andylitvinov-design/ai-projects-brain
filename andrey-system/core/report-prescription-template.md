# Report Prescription Template — Andrey Li

This file is the canonical template for Part 2: `Назначение` in client reports.

Use this file when writing any report prescription block.

Main rule:

**Назначение = короткая прямая рекомендация: приоритеты, покупка, приём, курс, повторная проверка.**

Do not turn prescription into diagnosis or remedy analysis.

---

## 1. Required structure

Always use this structure:

```md
## 2. Назначение

Отобранные эссенции:

#1. В первую очередь подходят: Эссенции Баха:
1) ... (...)
2) ... (...)

#2. Дополнительно:
3) ... (...)
4) ... (...)

Рекомендую купить в любой натуропатической аптеке или на Amazon.

Принимать:
- смесь: чуть воды и по 4 капли каждого препарата;
- 2–4 раза в день.

Курс: 2 недели.

Повторная проверка — что изменилось — через 1–2 недели.

Мне можно написать по готовности, я проверю состояние и дам анализ, рекомендации или коррекцию назначения.
```

---

## 2. Strict rules

- Keep this block short.
- Use priority groups: `#1. В первую очередь` and `#2. Дополнительно`.
- In parentheses after each remedy, give a short client-readable emotional marker, e.g. `(печаль)`, `(опора)`, `(тревожность)`, `(беспокойство)`.
- Include where to buy: naturopathic pharmacy or Amazon.
- Include exact intake: water + 4 drops of each remedy, 2–4 times a day.
- Default course is **2 weeks**.
- Follow-up is **1–2 weeks**.
- Include the closing line: `Мне можно написать по готовности...`

---

## 3. Do not use these old formats

Do not write:

```md
Ключевые сейчас:
...

Принимать / использовать:
...

Почему такой порядок:
...
```

Do not write:

```md
Они поддерживают:
...

Формат:
...

Если принимать Bach внутрь:
...
```

Do not write a long explanation of every remedy in `Назначение`.

---

## 2. Назначение

## 5. Appendix rule connected to prescription

If the report has Part 4: `Приложение`, each remedy must include a clear **послание**.

Every remedy in the appendix should answer:

```md
Что этот препарат возвращает человеку?
Какое поддерживающее послание он несёт?
```

Good appendix style:

```md
Gorse — послание: путь ещё не закрыт. Он возвращает тихую надежду и право снова попробовать без насилия над собой.
```

Bad appendix style:

```md
Gorse — препарат для снижения безнадёжности.
```

The appendix must inspire and support, not repeat diagnostic functions.
