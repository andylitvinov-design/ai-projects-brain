# Report Prescription Template — Andrey Li

This file is the canonical template for Part 2: `Назначение` in client reports.

Use this file when writing any report prescription block.

Main rule:

**Назначение = короткая прямая рекомендация, не диагностика.**

---

## 1. Required structure

Always use this structure:

```md
## 2. Назначение

Ключевые сейчас:
- ...
- ...

Принимать / использовать:
- ...

Срок: 2 недели.

Проверить через 2 недели:
- ресурс;
- основной симптом / эмоцию;
- реакцию на препараты;
- что стало легче / что осталось.

Почему такой порядок:
один короткий абзац.
```

---

## 2. Strict rules

- Do not write a long support-plan.
- Do not explain every remedy again.
- Do not use `Они поддерживают:`.
- Do not use `Формат:`.
- Do not use `Дистанционная поддержка:`.
- Do not use `Если принимать Bach внутрь:`.
- Do not use 3–5 days or 5–7 days as the default cycle.
- Default assignment term is **2 weeks**.
- Extra remedies are allowed only if truly needed and only as one line: `Дополнительно: ...`.

---

## 3. Good example

```md
## 2. Назначение

Ключевые сейчас:
- Gorse
- Centaury

Принимать / использовать:
Gorse + Centaury.

Срок: 2 недели.

Проверить через 2 недели:
- общий ресурс;
- надежду;
- границы;
- реакцию на препараты;
- что стало легче / что осталось.

Почему такой порядок:
Сначала укрепляем Землю и Металл: надежду, опору и границы. Тогда движение пойдёт мягче и без внутреннего рывка.
```

---

## 4. Bad example

Do not write this:

```md
Отобранные поддержки сейчас:
Gorse — вернуть надежду.
Mimulus — снизить страх.
Centaury — укрепить границы.
Impatiens — снизить раздражение.

Они поддерживают:
...

Формат:
1. Дистанционная поддержка...
2. Если принимать Bach внутрь...

Смотреть реакцию 5–7 дней.
```

This is too long and not Andrey's final prescription style.

---

## 5. Appendix rule connected to prescription

If the report has Part 4: `Приложение`, each remedy must include a clear **послание**.

Every remedy in the appendix should answer:

```md
Что этот препарат возвращает человеку?
Какое поддерживающее послание он несёт?
```

Good appendix style:

```md
Gorse — послание: путь ещё не закрыт. Он возвращает тихую надежду и право снова попробовать без насилия над собой.
```

Bad appendix style:

```md
Gorse — препарат для снижения безнадёжности.
```

The appendix must inspire and support, not repeat diagnostic functions.
