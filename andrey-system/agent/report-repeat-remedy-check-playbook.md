# Repeat Remedy Check Playbook — Report Agent / Auditor

Status: canonical operational playbook
Primary standard: `andrey-system/core/report-repeat-remedy-check-standard.md`

Use this playbook when writing or auditing repeat reports with previous remedies, Bach essences, homeopathy, tinctures, or other supports.

---

## 1. First decision

Before writing, classify the task:

```md
Is this a repeat check?
```

It is a repeat check if there are old remedies, previous support, or a question like:

- что актуально сейчас;
- что ушло;
- что оставить;
- что добавить;
- повторная проверка;
- старые препараты уже отработали?

If yes, do not use a simple new-diagnosis template.
Use the repeat structure.

---

## 2. Required output skeleton

```md
1. Диагностика
2. Что изменилось
3. Что показывают препараты сейчас
4. Вывод
5. Решение
6. Назначение
7. Ожидаемое направление поддержки
8. Приложение. Послания препаратов
```

This is the canonical order.

---

## 3. The most important audit gate

Ask:

```md
Does the report explain what shows that old remedies left or became background?
```

If no, the report fails as a repeat check.

Weak:

```md
Почти ушли / стали фоном: Agrimony, Olive, Vine, Clematis, Water Violet.
```

Strong:

```md
Ушли или стали фоном препараты, которые показывали старый слой:
- Olive — полное истощение.
- Vine — жёсткое давление и попытку управлять ситуацией.
- Clematis — уход из контакта.
- Water Violet — холодную дистанцию и закрытость.
- Agrimony — маскировку боли через “всё нормально”.

Это говорит, что стало меньше защитного слоя.
Больше настоящести.
Но вместе с этим ближе проявился внутренний стресс.
```

---

## 4. Remedy function rule

Do not list remedies as names only.

Every old remedy must show:

```md
old remedy → old layer it represented
```

Every current remedy must show:

```md
current remedy → current function in mechanism
```

Example:

```md
Sweet Chestnut — внутренний предел: старый способ держаться уже не работает, нужна новая опора.
```

---

## 5. Psychodynamic formula

Every repeat check needs one concise formula:

```md
Психодинамика ситуации сейчас:
"..."
```

Then:

```md
Главный bottleneck — ...
```

Do not replace bottleneck with a long paragraph.

---

## 6. Solution rule

`Решение` must name the support direction, not only remedies.

Good:

```md
Главная задача сейчас — восстановить чувство личной опоры.
Чтобы не нужно было всё контролировать, стараться всё удержать и цепляться за связь.
```

Weak:

```md
Принимать Chicory, Sweet Chestnut, Star of Bethlehem.
```

---

## 7. Effect wording

Use safe effect language.

Good:

```md
Ожидаемое направление поддержки: может стать больше внутренней силы, спокойствия и способности опираться на себя.
Проверяем: меньше цепляния за связь, меньше внутреннего напряжения.
```

Avoid guaranteed outcomes.

---

## 8. Auditor checklist

```md
Повторный формат выбран: да/нет
Блок “Что изменилось” есть: да/нет
Старые препараты раскрыты через старый слой: да/нет
Есть объяснение, что говорит об их уходе: да/нет
Новые препараты раскрыты через текущий механизм: да/нет
Есть psychodynamic formula: да/нет
Есть bottleneck: да/нет
Есть решение до назначения: да/нет
Назначение разделено на основное и дополнительное: да/нет
Есть проверка через 1–2 недели / нужный срок: да/нет
Эффект сформулирован безопасно: да/нет
```

If any of these are missing, revise before sending.
