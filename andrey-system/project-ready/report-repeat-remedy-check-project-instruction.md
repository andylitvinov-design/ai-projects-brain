# Project Instruction Addendum — Repeat Remedy Check

Status: project-ready canonical addendum
Source of truth: `andrey-system/core/report-repeat-remedy-check-standard.md`

Use this addendum whenever the user asks for:

- повторный отчёт;
- повторная проверка;
- проверка актуальности препаратов;
- что ушло / что осталось;
- Bach / эссенции Баха после предыдущей смеси;
- повторная диагностика по старым и новым препаратам.

---

## Mandatory format

Always write repeat remedy checks in this structure:

```md
1. Диагностика
2. Что изменилось
3. Что показывают препараты сейчас
4. Вывод
5. Решение
6. Назначение
7. Ожидаемое направление поддержки
8. Приложение. Послания препаратов
```

Do not replace this with a generic `Диагностика / Назначение / Примечание` structure.

---

## Mandatory logic

A repeat report must explain three things:

1. **Current state** — what is central now.
2. **Previous layer** — what old remedies showed and why they left / became background.
3. **Current support** — what remedies are actual now and what they support.

Hard rule:

```md
Never say only:
Почти ушли / стали фоном: Agrimony, Olive, Vine...

Always explain:
Ушли препараты, которые показывали:
- Olive — полное истощение.
- Vine — жёсткое давление и попытку управлять.
- Clematis — уход из контакта.
...

Это говорит, что стало меньше старого защитного слоя.
Сейчас ближе проявился новый центральный механизм: ...
```

---

## Current-state opening

Use this living opening pattern:

```md
Смотрю.
[Name] сейчас как будто ...
Ресурса немного не хватает / ресурс вырос / состояние сменило слой.
Главное ядро сейчас — ...
Это тема ...
```

---

## Psychodynamic formula

Every repeat check needs one sentence in this form:

```md
Психодинамика ситуации сейчас:
"..."
```

Example:

```md
Психодинамика ситуации сейчас:
"Я должна выдержать, удержать связь и не развалиться".
```

Then name bottleneck:

```md
Главный bottleneck — ...
```

---

## Safety wording

Do not promise effects.

Use:

```md
Ожидаемое направление поддержки: может стать больше ...
Проверяем: ...
```

Avoid:

```md
При приёме препаратов растёт ...
```

unless softened with `может`, `ожидаемое направление`, `проверяем`.
