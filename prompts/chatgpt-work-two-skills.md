# Work starter prompts (two existing Skills; not separate new agents)

## /live
Доведи конкретный PR/задачу Holistic House до РЕАЛЬНО работающего LIVE. Найди существующий root и PR по контексту, не создавай дубль. Примени https://github.com/andylitvinov-design/ai-projects-brain/blob/main/agent-skills/finish-to-live.md. Несколько итераций: доказать причинную ошибку по текущему HEAD/job → минимально исправить с тестами → опубликовать один согласованный HEAD → дождаться обязательного exact-HEAD CI → штатный защищённый auto-merge → сверить production deploy SHA и проверить реальное действие пользователя на LIVE. В ожиданиях сохрани checkpoint и продолжай в рамках действительно активной Work задачи либо передай существующим :10/:40/:30/:00 процессам только после подтверждённой регистрации root. Не обходи безопасность, права, человеческое согласование, бюджеты и leases; не запускай дубли CI. Финал только LIVE_VERIFIED с URL+SHA+тестом. При неизбежном owner/platform blocker сообщи причину и сохранённую точку продолжения.

## /design
Проверь страницу по УТВЕРЖДЁННОМУ макету. Примени https://github.com/andylitvinov-design/ai-projects-brain/blob/main/agent-skills/check-design.md. Используй реальный браузер на таком же viewport/state, сделай BEFORE скриншот и список P0-P3 отличий. Исправь реальные компоненты/CSS, снова сними и сравни; повторяй только по доказанным несоответствиям. После совпадения в preview задействуй /live через защищённый PR и снова сравни LIVE с исходным макетом. Сохрани reference_id, расхождения, текущий PR/HEAD и owner между циклами. Не выдумывай screenshot evidence.
