# Harness Proposals

This file stores proposed changes to the agent harness.

Harness means:

- command adapters;
- boot router rules;
- memory schemas;
- validation gates;
- installer templates;
- tool-use workflows.

Do not treat proposals as active rules until validated.

## Proposal format

```md
## YYYY-MM-DD — Proposal title

Status: candidate | proposed | validated | active | archived | replaced  
Scope: project | command | global  
Risk: low | medium | high  

Problem:
- ...

Minimal harness change:
- ...

Expected behavior change:
- ...

Regression risk:
- ...

Validation plan:
- ...

Decision:
- pending | accepted | rejected | needs user decision
```
