# Session Summary Template

Use this before compacting, switching to a new chat, or handing off a long Codex task.

```md
## Session Summary

Repo:
- owner/name

Branch / PR:
- branch:
- PR:

Goal:
- ...

Project memory read:
- projects.md:
- PROJECT.md / CODEX_BRIEF.md:
- STATE.md / LOG.md:

Files studied:
- path — why it matters

Findings:
- ...

Changes made:
- ...

Changed files:
- path — change summary

Checks run:
- command — result

Checks not run:
- command/check — reason

Risks / needs verification:
- ...

STATE.md / LOG.md update:
- needed / not needed
- proposed entry, if needed:

Next exact action:
- ...
```

Rules:

- Keep it short.
- Do not include secrets or env values.
- Do not include raw long logs.
- Include exact failing command/check when relevant.
- Prefer this summary over rereading the whole session.
