## Canonical Upgrade Candidate Score rubric

`priority = impact * urgency * completion_probability / risk`

- **Impact:** 1 = minor/local; 3 = material single-project value; 5 = critical business, safety or multi-project value.
- **Urgency:** 1 = optional; 3 = active time-sensitive gap; 5 = failed production, security exposure or unresolved delivery carryover.
- **Completion probability:** 1 = speculative; 3 = feasible with meaningful missing evidence; 5 = implementation complete and verification-only.
- **Risk:** 1 = bounded verification/recovery; 3 = contained code change with operational risk; 5 = auth/payment/provider/data or irreversible risk.
