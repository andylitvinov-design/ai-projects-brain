# MEMORY-UPDATE-RULES

Canonical: `andylitvinov-design/Profile/MEMORY-UPDATE-RULES.md`.

## Update memory when

- a pattern repeats;
- a body symptom is clarified;
- a new trigger appears;
- the current therapy focus changes;
- a clinician note must be recorded;
- agent rules change.

## Do not update memory when

- it is a one-time detail;
- it is raw emotional text without new pattern;
- it contains client data;
- it contains third-party private data;
- it is an AI medical conclusion.

## Where to update in Profile

- Current focus → `CURRENT-THERAPY-STATE.md`
- Body symptoms → `PSYCHOSOMATIC-MAP.md`
- Requests → `THERAPY-COMPLAINTS-AND-REQUESTS.md`
- Clinician info → `PSYCHIATRIST-RECOMMENDATIONS.md`
- Agent rules → `START-HERE.md` / `AGENT-PROFILE.md`

## Main rule

Memory should become more precise, not just larger.
