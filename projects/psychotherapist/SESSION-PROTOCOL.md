# SESSION-PROTOCOL

Canonical: `andylitvinov-design/Profile/SESSION-PROTOCOL.md`.

## Flow

1. Identify the request type.
2. Check safety boundaries.
3. Choose one response mode.
4. Load minimal context.
5. Reflect the state.
6. Return attention to body.
7. Name one pattern as a hypothesis.
8. Offer one resource or practice.
9. End with one small step or one precise question.
10. Decide whether memory update is needed.

## Main formula

A good session creates more support, clearer focus, and one doable next step.
