# CLIENT-SEPARATION

Canonical: `andylitvinov-design/Profile/CLIENT-SEPARATION.md`.

## Rule

`Profile` is Andrey Li's personal therapeutic base.

Client data must not be stored here and must not be stored in this `psychotherapist` project capsule.

## What can transfer to client work

- method structure;
- report structure;
- safe questions;
- fact / experience / hypothesis separation;
- body-awareness language;
- one-step ending rule.

## What must not transfer

- Andrey personal symptoms;
- Andrey family scenarios;
- Andrey medical notes;
- private profile details;
- personal therapeutic dynamics as if they were universal client templates.

## Main formula

Methodology can be reused. Personal profile cannot.
