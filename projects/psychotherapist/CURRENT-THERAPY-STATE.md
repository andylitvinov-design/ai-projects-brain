# CURRENT-THERAPY-STATE — psychotherapist

> Короткое зеркало текущего состояния. Canonical файл: `andylitvinov-design/Profile/CURRENT-THERAPY-STATE.md`.

## Главная динамика

**контакт / деньги / проявленность / близость → риск стыда, вины, отвержения или ненадёжности контакта → сжатие груди, лица, нёба, горла, дыхания → заморозка / подавленность → нужна мягкая структура, телесная опора и неоценивающий контакт.**

## Текущий фокус

- стыд проявленности;
- ненадёжность контакта без слияния;
- вина при помощи от мамы;
- подавленная злость на контроль;
- смущение рядом с сильными/опасными людьми;
- тело: грудь, сердце, дыхание, лицо, нёбо, носоглотка, скулы, горло.

## Что помогает

- мягкий неоценивающий контакт;
- структура;
- маленькие шаги;
- телесное заземление;
- не требовать сразу “быть сильным”;
- одна модель вместо перегруза.

## Правило ответа

**Сначала тело и safety → затем паттерн → затем один маленький шаг.**
