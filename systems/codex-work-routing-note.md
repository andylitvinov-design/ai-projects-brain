# Codex Work Routing Note

Use `/planner` before execution when a task is abstract, broad, risky, or unclear.

Use `/delivery` for the final execution task after the work is clear enough.

Use `/audit` for inspection of existing code, data, PRs, sites, calculations, or production behavior.

Use `/supergoal` for large multi-stage goals.

Clear tasks should go directly to a strong delivery task. Do not create a separate prompt audit mode.
