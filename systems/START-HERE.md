# Start Here

1. Read `README.md`.
2. Read `projects.md`.
3. Find the matching project in `projects.json` or
   `projects.md`.
4. Open that project's `STATE.md`.
5. Work through the repo workflow in
   `systems/codex-project-workflow.md`.

If project memory exists -> use `STATE.md` as source of
truth before making changes.

If a project `STATE.md` or `LOG.md` is missing, mark it
`needs verification`.

After every project task, propose `STATE.md` and `LOG.md`
updates before final report.
