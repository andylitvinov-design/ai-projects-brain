### HH-ES-TEST-CTA — P1 / S / NEW · CONFIRMED_SOURCE
- **URL посетителя:** https://holistichouse.vercel.app/es/services. **Источник:** [`components/services-studio-offers.tsx`](https://github.com/andylitvinov-design/books/blob/fe775f20fe11814681b9bfebe17a5b75db42d098/components/services-studio-offers.tsx) в exact production Git commit.
- **Свидетельство и воспроизведение по исходнику:** для `id:"tests"` прописано `href: locale === "es" ? "/es/client" : "/" + locale + "/client/tests"`. При этом в маршрутах `app/[locale]/client` доступен `tests/page.tsx`, отдельного `client/page.tsx` нет. Для остальных локалей карточка открывает `/en/client/tests` и `/ru/client/tests`. Возможность middleware rewrite или внешний live redirect полностью не проверялась; **не заявляем установленный HTTP 404**.
- **Сценарий/влияние:** испаноязычный посетитель нажимает «начать бесплатные тесты» из Services и может попасть не в каталог тестов; это риск потери перехода и доверия.
- **Изменение:** проверить продуктово желаемую точку (прямой интерактивный `/es/client/tests` либо публичный `/es/tests` с последующим явным CTA); для одинаковой функции построить locale-aware href без ES-исключения на неизвестный route. Не перенаправлять на приватные результаты и не менять политику авторизации.
- **Acceptance / проверка:** у EN/RU/ES адрес карточки ведёт на реально существующую целевую страницу; по 320/390/768/1365px CTA читаем и виден; получить фактические HTTP code/final URL и пройти один гостевой тест без сохранения чувствительных ответов; приватный кабинет остаётся noindex.
- **Риск/зависимость:** даже правильный URL теста может потребовать регистрации для записи результата; уточнить guest/public обещание; измерений перехода нет. Связать с [conversion issue #990](https://github.com/andylitvinov-design/books/issues/990), не дублировать.
